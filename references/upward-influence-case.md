# 向上争取一页纸（无决策权推动者）

> 本文件是业务体检的按需参考，不新增阶段决定权。触发条件：用户明确无决策权，或说「推不动」「只有执行权」「上面让我做但没批」「没数据证明该往哪改」。

## 一句话立场

**推动者不是没价值，是缺一个能把判断变成论据的人。**

无决策权的用户，最需要的不是「你该做哪个决策」（他做不了），而是「帮他把证据、取舍和 ROI 打包成一份向上争取授权的一页纸」。业务体检的交付目标据此切换：**从给决策建议，转为帮其建立有依据的向上论点。**

## 触发信号

出现以下任一时，进入本模式：

- 用户说「推不动」「没人听我的」「上面不批」「我只有执行权」。
- 用户被要求推进某件事，但无预算、无人、无跨部门授权。
- 用户的核心痛点不是「不知道方向」，而是「没法让有权的人信服」。

## 交付目标切换

| 普通经营者自诊 | 无决策权推动者 |
| --- | --- |
| 交付：给你决策建议 | 交付：帮你打包向上争取的材料 |
| 目标：替用户判断 | 目标：替用户建立论据 |
| 动作：可执行的经营动作 | 动作：可执行的「争取授权」动作 |

## 向上争取一页纸（固定六块）

1. **当前真实瓶颈**：业务卡在哪一关、哪个机制在限制结果。
2. **三条已发生证据**：只写 `[已确认]` 的已发生行为，不写假设、不写「我们觉得」。
3. **最贵的误判**：继续按常见答案推下去，会浪费什么（时间／钱／机会）。
4. **一个最小验证动作**：最便宜、可撤回、能在一个周期内出结果的那一步。
5. **改判条件**：出现什么新证据就换方向。
6. **需要申请的授权**：具体到「要谁批、批什么、多少钱、多久、批了先做什么」。

前五块负责「让论点站得住」，第六块负责「让争取有落点」。没有第六块，前面再对也只是「分析得不错」，推不动。

## 规则

- 不替用户做决策、不承诺结果；只帮他把判断变成论据。
- 不越权替用户向管理层要资源——「申请」和「决定」是两回事，写清这是申请。
- 证据不足时，不硬编证据填充一页纸；宁可在「三条证据」处写「当前缺口」并给出最便宜的补证动作。
- 涉及预算、人力、跨部门或组织调整时，明确这是向上申请，最终由有权者决定，不由本工具箱代办。

## 收口

完成一页纸后，回传业务体检：这不是新的阶段结论，而是同一诊断的「向上表达」。若用户后续拿到了授权、带着新证据回来，业务体检照常复核阶段，不把「争取授权」本身当成经营结果。
