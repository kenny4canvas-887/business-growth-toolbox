# S6 财务口径与边界

每项计算先建立同口径记录：对象／范围、期间、币种、分子、分母、来源和证据状态。任一项缺失即输出 `数据不可得`，不得计算。来源可为已确认财务报表、管理报表或可追溯原始记录；预测、集团合并总量和不同范围数据不得混算。

客户数据不足时，可用公开同业数据说明“可观察什么”，或用教学算例说明“如何计算”，但必须与客户证据分区。公开参照保留披露对象、期间、来源和可比边界；教学算例明示假设。这些数字不得填入客户指标的分子或分母，也不得被描述为客户或行业真实水平。

## 最低公式

### ROI

`ROI = 可归属的增量收益 / 对应增量投入`

对象／范围是同一 `portfolio_unit` 的明确增量动作；期间、币种、分子（可归属的增量收益）、分母（对应增量投入）、来源和证据状态必须齐全。ROI 与 ROE 不得混用。

### ROE

`ROE = 同期归属权益持有者净利润 / 同口径平均权益`

对象／范围是可归属权益持有者的同口径主体；期间、币种、分子（同期归属权益持有者净利润）、分母（同口径平均权益）、来源和证据状态必须齐全。ROI 与 ROE 不得混用。

### 营运资金强度

`营运资金强度 = 同口径经营性营运资金 / 同期收入`

对象／范围是同一经营单元的经营性项目；期间、币种、分子（同口径经营性营运资金）、分母（同期收入）、来源和证据状态必须齐全。负营运资金不自动等于经营健康。

### 数量盈亏平衡点

`数量盈亏平衡点 = 固定成本 / 单位贡献`

对象／范围是同一产品、服务或渠道；期间、币种、分子（固定成本）、分母（单位贡献）、来源和证据状态必须齐全。单位贡献非正时输出 `数据不可得`，不得计算。

### 收入盈亏平衡点

`收入盈亏平衡点 = 固定成本 / 贡献毛利率`

对象／范围是同一产品、服务或渠道；期间、币种、分子（固定成本）、分母（贡献毛利率）、来源和证据状态必须齐全。贡献毛利率非正时输出 `数据不可得`，不得计算。
