# S5 前向评测案例

这些案例只校准阶段和证据边界，不证明真实企业经营结果，不得补造经营数字。

| 场景 | 应有判断 | 禁止误判 |
|---|---|---|
| To C 连锁单店已在同口径期间贡献利润为正，SOP、培训、质控和区域团队有执行记录；复购改善带来口碑获客，持续溢价未伤害留存 | 可进入 S5；目标城市可比且容量可承接时才建议持续复制 | 不能用品牌总收入替代单店盈利 |
| To B 服务收入增长但只给预测毛利率，实施和售后成本未归集 | 返回 K4，补同口径盈利证据 | 不能因融资或订单额进入 S5 |
| 产品已盈利并形成标准，但只声称“用户越多价值越大” | 继续 S5，标记待验证循环并先补增强证据 | 循环故事不能直接称为飞轮 |
| 高毛利来自短期促销、特殊客户或暂时供给短缺 | 继续 S5 或先补条件；护城河或定价权仍待验证 | 高毛利不能直接证明定价权 |
| 单点盈利主要依赖创始人销售和手工交付 | 有限复制或先补条件，先验证系统、组织和标准 | 不能把个人能力写成复制系统 |
| 获客、留存或增购尚未在同一增长单元重复 | 返回 K3 | 不能用一次性增长证明复制成立 |
| 多个成熟业务单元均可复制，当前问题是保留、优化、收缩或更新组合 | 建议复核 S6 | S5 不做成熟组合取舍 |

每例都应输出 `[已确认]`、`[假设]`、`[缺口]`，一个最弱连接、一个 30 天验证及停止线；不得自行修改 `action_stage`，不得调用其他行动 Skill。
