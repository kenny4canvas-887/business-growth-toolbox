# S5 稳步复制（scale-with-control）

> 这是 BMI 业务增长工具箱的八个阶段模块之一，回答「已盈利单元能否跨区域、门店、团队或渠道受控复制」。
> 前置：只有根 `SKILL.md`（业务体检）已确认 `action_stage=S5` 时，才由它加载本模块。本模块不重新诊断阶段，不自行修改 `action_stage`，不调用其他阶段模块。
> 收口：四闸门结论回传业务体检，复核是否进入 S6。

## 触发边界

只有 `action_stage=S5` 已由业务体检确认，且用户要判断已盈利经营单元能否跨区域、门店、团队或渠道复制时，才使用本模块。直接调用时也必须提供完整交接对象；否则返回业务体检。

本模块不重新诊断阶段，不自行修改 `action_stage`，不得调用其他阶段模块。它只回传新增证据与 `recommended_review`，最终阶段仍由业务体检决定。

S5 不重做 K3 的增长重复性，也不重做 K4 的收入成本和资源优化。缺少重复获客、留存或增购证据时返回 K3；缺少已发生的盈利或经营效率证据时返回 K4；成熟组合需要保留、优化、收缩或更新时建议复核 S6。

## 显性专业价值

S5 必须追问：**复制到下一个单元时，哪一环最可能先断**。缺少会改变复制决定的证据时，先说明为什么不能直接判断，并只问一个决定性问题；不把门店数、规模或飞轮故事当成复制证明。

S5 的顾问论点是：**扩张不是多开几个单元**。只有成功能逐步脱离创始人、明星员工、特殊渠道和一次性红利，并由系统、组织和标准稳定复现，才形成可持续飞轮。

完整输出和行动 HTML 首屏固定写明：`核心判断`、`关键机制`、`为什么不是另一个常见答案`、`改判证据`。结论要鲜明，证据状态要诚实；不寻常来自机制洞察，不来自冒犯性标签。

## 输入契约

消费公共交接对象：`schema_version` 固定为 `1.0`，并读取 `scope`、`context_stage`、`action_stage`、`business_type`、`confirmed_facts`、`working_assumptions`、`evidence_gaps`、`target_30d` 与 `stage_payload`。

`stage_payload` 只承载：`replication_unit`、`profit_engine`、`proven_results`、`standard_core`、`local_variations`、`target_replication`、`capacity_constraints`、`flywheel_loop`、`defensibility_signals`。缺失值保留“待验证”，不得补造。

## 四闸门

1. **盈利成立**：同一经营单元、期间和成本边界有已发生证据证明贡献利润为正且不是一次性结果，并说明固定成本、获客、交付、售后、扩张投入与现金约束。
2. **复制载体成立**：关键动作已经由系统、组织和标准承接，包括岗位责任、培训、质量控制、数据反馈与异常处理；不能持续依赖创始人、明星销售、特殊客户、补贴或一次性渠道。
3. **增强循环出现**：至少一条客户、数据、供给、品牌、渠道或成本的强化关系有可观察信号。仅有循环故事时标记“待验证循环”，不称为已形成飞轮。
4. **防御性出现**：已发生证据支持护城河或定价权，并记录替代解释与失效条件。高毛利、知名度、专利数量或管理层表述不能单独证明防御性。

只有四闸门均有已发生证据，才可建议“持续复制”；否则在“有限复制”“先补条件”“暂停扩张”中选择一个，不给结果保证。详细判断按[方法参考](modules/scale-with-control/references/methods.md)，边界校准按[评测案例](modules/scale-with-control/references/evaluation-cases.md)。

## 输出契约

先给阶段决策卡，再给盈利复制飞轮图与复制条件表：

- 唯一结论及为什么仍是 S5；
- 盈利口径、事实、假设和缺口；
- 飞轮节点、增强方向、证据状态与最弱连接；
- 系统、组织、标准、本地变量和不可复制依赖；
- 护城河／定价权证据、替代解释与失效条件；
- 一个 30 天复制验证、完成标志、停止线与改判证据；
- `recommended_review`：继续 S5、返回 K3、返回 K4、暂停或建议复核 S6。

完整交付使用 `modules/scale-with-control/scripts/render_s5_scaling_flywheel.py --input JSON --output REPORT.html` 生成 S5 HTML 行动报告，并与诊断 HTML 使用安全的本地相对 `.html` 链接。无法生成时标记部分交付，不宣称双报告完成。
