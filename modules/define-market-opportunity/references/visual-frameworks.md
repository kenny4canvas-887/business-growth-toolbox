# K0 视觉框架

## 核心画布

完整版本默认生成并显示一张 K0 HTML 行动报告页面，内嵌一张 1600×1100 的“K0 方向机会画布”；单独画布可输出 SVG。两者与正文共用同一组 `[已确认]`、`[假设]`、`[缺口]` 证据。画布覆盖决策、外部窗口、替代方案、优先探索对象、生态价值位、方向取舍、证据边界、三步证据冲刺、排除范围和停止线。

## 画布结构

- 顶部：标题、阶段、当前决策与带证据标签的方向判断。
- 中部：外部机会窗口、现有替代方案、优先探索对象、生态价值位、候选方向与主取舍、证据边界六格。
- 底部：三步证据冲刺、明确不做和停止线。

## 渲染输入

使用 `scripts/render_k0_opportunity_canvas.py` 读取 UTF-8 JSON。`sections` 必须恰好包含 `window`、`alternatives`、`target`、`ecosystem_position`、`direction_choice`、`evidence`；每条内容必须带证据标签。`evidence_sprint` 恰好 3 项，`exclusions` 和 `stop_line` 均为非空字符串数组。过长内容在渲染器中有界换行或截断，所有文本先进行 SVG 安全转义。

完整交付返回已生成 HTML 的绝对路径链接；只有单独画布才显示 SVG。生成失败可用 Markdown 说明进展，但不算正式报告验收完成。仅预览不可用时保留 HTML 交付并说明未做视觉验收。图文使用同一组事实。

## 辅助画布边界

只有另一项最大不确定性会改变结论时，才可在核心画布外最多推荐一张辅助画布。环境趋势画布、蓝海策略图、K0 商业模式现状画布和五步愿景画布当前只是映射参考，未授权实现多个渲染器。
