# K3 评测案例

本文件记录阶段三方法边界案例。完整前向行为复测仍以已锁定的 15 个基线案例为准，本阶段不把静态合同视为行为 GREEN。

| 案例 | 阶段三必须观察 | 禁止项 |
| --- | --- | --- |
| To C 流量上升但复购下降 | 将流量与复购放入同一增长单元，先判断客户质量和关系/收入缺口 | 仅因流量增长建议继续加投 |
| To B 线索增加但有效商机减少 | 比较目标客户质量、关键转化、销售周期与渠道成本线索 | 用线索量证明渠道有效 |
| 混合业务中企业采购但个人未采用 | 企业/渠道侧和个人侧证据分别记录，保留最终用户采用缺口 | 用采购合同替代个人采用 |
| 多渠道数据周期不同 | 标记渠道数据周期不同、口径不可比，先统一周期、客户与转化定义 | 直接排序渠道或生成预算比例 |
| 单一大客户收入上升 | 记录为当前客户收入事实，保留同类客户重复转化、采用与收入缺口 | 宣称它能证明当前增长单元已可重复 |
| 四条候选路径都有零散支持 | 只选一个主路径，保留一个次选和至少一个暂缓方向，写明反转证据 | 四条路径同时推进或生成伪精确总分 |
| 团队希望一次填完所有增长工具 | 按最大不确定性调用一个核心方法；只有会改变主路径时增加一个辅助方法 | 对客户机械展示工具目录 |
| 计划扩大投放但没有同口径基线 | 先完成基线卡，再执行主路径实验卡和重复性与质量卡 | 把计划、目标或预测写成新增已发生证据 |

以上案例均要求：一个特殊大客户、集团渠道或公司整体收入不能证明当前增长单元已可重复。
