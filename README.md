# BMI 业务增长工具箱

> 一个包，八个阶段模块。先判断你的生意卡在 K0—S7 哪一关，再只加载最能解决那一关的方法。
> An install-once toolbox with eight stage modules. One entry — 业务体检 (Business Checkup) — routes to the single stage that matters most.

经营者最常问的不是"用什么工具"，而是"我现在最该解决哪一件事"。业务体检就是这个判断入口：先看清当前生意最该解决的一件事——先做什么、暂时不做什么，以及用什么结果检验这个决定。

八个阶段模块不对外单独暴露，只有业务体检按证据确认阶段后，才加载其中一个。你不需要先理解 K0—S7。

---

## 它能帮谁

- **企业经营者 / 老板**：看清生意卡在哪一关，拿到下一步动作。
- **大企业部门负责人（P&L）**：把"收入增长掩盖的成本与资源约束"暴露出来。
- **培训管理者 / L&D**：先诊断业务阶段，再决定培训卖什么——不卖通用能力课。
- **无决策权的推动者**：把证据、取舍、ROI 打包成一份向上争取授权的一页纸。
- **管培生 / 轮岗新人**：教你问对问题、找到第一份证据、学一个判断。

---

## 八个阶段

| 阶段 | 对外名称 | 回答什么 |
| --- | --- | --- |
| K0 | 选方向 | 这个方向要不要做 |
| K1 | 找真需求 | 哪一类客户在什么场景下真的会行动 |
| K2 | 做最小方案 | 最小价值能否被真实使用并产生结果 |
| K3 | 找增长瓶颈 | 同一增长单元的获客、留存或增购能否重复 |
| K4 | 提效配资源 | 哪个收入、成本、交付或资源瓶颈最先限制放大 |
| S5 | 稳步复制 | 已盈利单元能否受控复制 |
| S6 | 经营取舍 | 哪个成熟单元该保留、优化、收缩或更新 |
| S7 | 转型建议 | 保留什么、停止什么、哪条新曲线值得验证 |

---

## 三种使用模式

- **经营者自诊**：你描述业务，工具给可纠正的阶段初判、先做什么、暂不做什么、用什么证据检验。
- **向上争取（无决策权）**：你只有执行权、推不动，工具帮你把证据、取舍、ROI 打包成一份向上争取授权的一页纸，不替你做不可逆决策。
- **学习式诊断（新手 / 管培生）**：你没业务背景、不知数据在哪，工具教你问对问题、找到第一份证据、学一个判断，不甩一句"证据不足"就停。

## 安装（WorkBuddy）

1. 左侧「专家 · 技能 · 连接器」→ 添加技能 → 上传本地技能包。
2. 选择 `business-growth-toolbox.zip`，系统自动配置，无需额外操作。
3. 对话中用「帮我看看我的业务」「不知道问题出在哪」「下一步该做什么」等触发即可。

> 八阶段模块由业务体检按证据加载，不单独出现在技能列表，唯一入口从结构层面保证。
